🔐 অ্যাডমিন লগইন

GitHub token দিয়ে লগইন করুন। Token শুধু আপনার এই ব্রাউজারে থাকে।

  1. এখানে ক্লিক করে Generate new token চাপুন
  2. Repository access-এ Only select repositories → bangla-lyrics সিলেক্ট করুন
  3. Permissions-এ Contents → Read and write দিন
  4. Generate করে token-টি কপি করে নিচে পেস্ট করুন

➕ নতুন গান যোগ করুন

⚖️ শুধু নিজের মৌলিক লিরিক্স বা যাচাইকৃত পাবলিক-ডোমেইন লিরিক্স পোস্ট করুন।
